# NTMS Exam Platform - Administrator Guide

## Role Responsibilities

### 1. Administrator (`ADMINISTRATOR`)
- User provisioning and role assignment.
- System-wide security enforcement and Entra ID tenant management.
- Audit log review and server performance monitoring.

### 2. Exam Creator (`EXAM_CREATOR`)
- Designing exams and defining passing scores, time limits, and instructions.
- Authoring questions across all 16 supported formats.
- Managing Case Studies, Simulations, and Hands-on Labs.

### 3. Candidate (`CANDIDATE`)
- Taking certification exams in Pearson VUE / Microsoft style UI.
- Utilizing built-in calculator, scratchpad notes, mark for review, and strikeout features.
- Downloading scorecards and domain performance analysis.
